# Rust와 C++의 언어 경계

[English](ffi.md) | [한국어](ffi_KR.md) | [프로젝트 README](../README_KR.md)

연결부는 객체보다 값을 전달하도록 설계합니다. Rust는 요청과 앱 상태를 소유하며,
공통 스키마로 변환된 결과도 소유합니다. C++가 소유하는 파서 내부 메모리는 호출이
진행되는 동안만 유효합니다.

- 파서 객체나 외부 라이브러리 객체를 언어 경계 밖으로 넘기지 않습니다.
- 빌려 받은 포인터를 호출이 끝난 뒤 보관하지 않습니다.
- C++ 진입점은 `noexcept`이며 구조화된 상태 값을 반환합니다.
- Rust는 추출 전에 네이티브 API와 스키마 리비전의 호환성을 검사합니다.
- 네이티브 오류 코드는 앱 로직에 도달하기 전에 Rust 오류로 변환합니다.
- 향후 파서가 반환하는 원본 바이트 데이터는 Rust가 소유하는 벡터로 전달합니다.

`cxx`는 언어 연결 코드와 컴파일 단계의 함수 시그니처 검사를 생성합니다.
파서 구현 자체를 메모리 안전하게 만들어 주지는 않습니다. 네이티브 코드에는 메모리 오류
검출 도구, 자원 제한과 향후 스캐너의 파서 격리를 적용해야 합니다.

역할 구분은 [아키텍처](architecture_KR.md)를, 자원 제한과 시간 제한을 적용할 수 있는 범위는
[파서 자원 제한](resource-limits_KR.md)을 참고합니다.
