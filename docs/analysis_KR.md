# Rust 메타데이터 분석

[English](analysis.md) | [한국어](analysis_KR.md)

`metaxtract-analysis`는 네이티브 파서 없이도 타입이 있는 `ExtractionRecord`를 분석합니다.
분석은 원본을 변경하지 않으며 필드·결과·바이트·비교 횟수 제한을 사용합니다.
지원하지 않는 해석을 만들어 넣지 않고 원본과 제한 사항을 보존합니다.

## 정규화

`normalize::normalize`는 추가 해석값, 디코딩 상태, 문제 목록을 반환합니다. 호출자는 새 분석
레코드를 저장하기 전에 해석값을 추가할 수 있으며 원본 관측값은 덮어쓰지 않습니다.
ISO/EXIF/PDF 날짜의 원문·정밀도·명시된 시간대를 보존합니다. 부분 날짜, 알 수 없는 시간대
(`-00:00`), 윤초에는 임의의 UTC 시각을 부여하지 않습니다. Windows FILETIME은 정수 범위를
검사합니다. GPS 도분초·방위·십진 좌표, 나노초 단위 길이, 비트레이트를 정규화하고 스트림과
항목의 범위를 분리합니다. 식별 정보 표시값은 보존하며 `identity_comparison_key`는 공백 정리와
소문자화만 합니다. 동일 인물 판정이나 유니코드 정규화는 수행하지 않습니다. 인코딩 이름은
정리하되 바이트 재디코딩은 C++에서 담당합니다. 미지원 필드는 원본에 남고 날짜 해석 실패는
문제로 반환합니다.

## 필드 출처와 타임라인

`provenance::field_lineage`는 지지·반대 관측값을 원본 태그, 파서·라이브러리, 가상 경로,
스트림, 추출 방법, 바이트 범위와 연결하고 잘못된 연결은 거부합니다. `timeline`은 충돌한
해석도 신뢰도·해결 상태와 함께 보존하며 파일시스템 시각을 별도 표시합니다. 절대 시각은
시간순으로 정렬하고 시간대 미확인·부분 날짜는 뒤쪽 별도 그룹에 원문과 정밀도를 유지합니다.
정렬이 시간대를 확정하거나 분 단위 날짜를 초 단위로 정확하다고 판정하지는 않습니다.

## 해석 교차 검증

`validation::reconcile`는 파서 이름 목록을 신뢰하는 대신 실제 관측값 연결에서 지지·반대,
충돌, 신뢰도, 해결 상태를 계산합니다. 같은 라이브러리의 래퍼는 한 계열로 계산하고 내장
파서는 ID 접두사를 기준으로 보수적으로 묶습니다. 시간대 미확인 또는 정밀도 범위가 겹치는
날짜는 충돌로 단정하지 않습니다. 확인된 상이한 시각·값은 대안으로 남깁니다. 신뢰 점수는
근거 분류값이며 통계적 확률이 아닙니다. 사용자 선택과 기각 상태도 식별 가능하게 보존합니다.

## 발견 사항

`findings::classify`는 규칙 ID·심각도·분류·원본 경로·근거 해석 및 관측값 ID를 반환합니다.
위치·식별 정보·로컬 경로 노출, 해석 충돌, 손실 디코딩, 불완전 추출, 형식 불일치, 능동 콘텐츠,
비정상 시각 순서를 분류합니다. 변조 징후는 추정이라고 명시하며 위조·악성코드로 확정하지
않습니다. 외부 네트워크 조회 없이 원본 근거를 검토할 수 있습니다.

## 중복 분석

`duplicates::exact`는 SHA-256/BLAKE3 전체 해시와 파일 크기가 일치하는 항목을 알고리즘별로
묶습니다. `fingerprint_content`는 호출자가 연 원본을 스트리밍하며 기록된 크기·SHA-256을
확인한 뒤 내용 기반 청크 해시를 만듭니다. `near`는 청크 집합의 Jaccard 유사도를 비교하며
짧은 파일에는 한계가 있는 후보 추정입니다. 바이트 동일성을 확정하지 않습니다.
`visual_fingerprints`는 C++이 디코딩한 RGB24 미리보기의 크기를 확인하고 명시한 방향을
반영한 64비트 dHash를 만듭니다. `visually_similar`는 해밍 거리 임계값을 적용합니다.
Rust에 이미지 디코더나 외부 실행 프로그램을 추가하지 않았습니다. 네이티브 미리보기가 없으면
시각 지문도 없으므로 호출자가 그 제한을 알려야 합니다. 알고리즘별 점수를 혼용하거나 유사도
결과만으로 증거를 자동 삭제하지 않습니다.

## 오프라인 지리 분석

`geo::locations`는 근거 ID와 같은 범위에서 명확하게 연결되는 촬영 시각을 보존합니다.
`clusters`는 반경 내 연결 성분과 날짜변경선을 처리하는 구면 중심을 계산하는 단일 연결
군집이며 DBSCAN은 아닙니다. 거리는 구형 지구 근사값입니다. `tracks`는 경로별 그룹 지정을
받아 긴 시간 간격에서 구간을 나누고 과도한 속도·동시각의 다른 위치를 표시합니다. 그룹을
지정하지 않은 파일은 서로 연결하지 않고 UTC 시각이 없거나 모호하면 미해결로 남깁니다.
트랙 인덱스는 입력 위치 목록을 참조합니다. GeoJSON은 경도·위도 순서이며 KML 문자열은
이스케이프합니다. 온라인 지도·지오코딩을 요청하지 않고 해수면 아래 GPS 고도도 보존합니다.

## 스캔·필드 비교

`diff::compare_records`는 누락과 명시적 null을 구분하고 객체 키·배열 인덱스를 타입으로
표시합니다. 원본 관측값 변화와 정규화 해석 대안을 따로 보여주며 ID·출처만 바뀌고 값이
같은 경우도 식별합니다. 시간대 미확인 값은 동등하다고 단정하지 않습니다. 큰 바이너리
필드는 길이·SHA-256으로 비교 표시하고 원본은 케이스에 남깁니다. `compare_scans`는 같은
스캔의 중복 경로를 거부하고 추가·삭제를 표시합니다. SHA-256·크기가 유일하게 일치할 때만
경로 이동 후보를 연결하며 누가 왜 이동했는지는 단정하지 않습니다.

## 구조화 검색과 저장 필터

`search::parse(scan_id, text)`는 공백으로 연결한 AND 조건, 따옴표 값, 앞의 `-` 부정을
지원합니다. 예: `mime=image/jpeg size>=1024 claim.metadata.author="Alice Smith"`,
`tag=review raw:exif`, `claim.metadata.created>=unix:1704067200`. `*`는 필드 존재를
확인합니다. 타입이 있는 `SearchExpression` API는 OR/AND/NOT 중첩도 지원합니다. 텍스트는
대소문자를 구분하고 숫자는 저장 타입으로 비교합니다. 크기는 u64 전체 범위를 유지하며 시각
범위는 명시적인 UTC 초를 사용합니다. `claim.key!=value`는 다른 대안이 있어도 일치값이
있는 레코드를 제외합니다. 일반 텍스트는 경로·MIME·해석·노트에서 찾고 원본 네임스페이스도
검색할 수 있습니다. 인코딩된 바이너리 내용은 일반 텍스트로 취급하지 않습니다.

`CaseWorkspace::search_records`, `count_search`, `search_facets`는 전체 케이스를 메모리에
올리지 않고 바인딩된 SQL·기존 인덱스·페이지 조회를 사용합니다. 포함 조건은 후보 인덱스
검색이 필요할 수 있습니다. 집계는 레코드 중복을 제외하고 표시값 제한 여부를 반환합니다.
커서는 전체 검색 조건·케이스·수정 시점에 묶입니다. `FilterQuery::Structured`로 저장할 수
있고 기존 필터도 읽습니다. 새 필터를 읽으려면 이 엔진이 필요하며 저장 작업은 감사 체인에
기록됩니다.

## 비식별화 프로필 미리보기

`redaction::preview`는 케이스·원본 바이트를 바꾸지 않고 별도 메타데이터 파생본과 변경 목록을
만듭니다. 정규 키 접두사, 원본 네임스페이스·필드명, 개인정보 필드, 전체 메타데이터를 선택해
제거하거나 마스크 문구로 바꿀 수 있습니다. 연결된 관측값, 같은 필드의 경쟁 해석, 충돌 참조로
적용 범위를 확장해 선택한 값이 다른 연결 표현에 남지 않게 합니다. 겹친 규칙의 동작이 다르면
거부하고 마스크는 원본 파서 출력이 아닌 생성된 파생값으로 표시합니다.

기본 개인정보 프로필은 인코딩된 페이로드와 비정형 진단·컨테이너 문맥도 제외합니다. 파일
경로·해시·파일시스템 날짜는 별도 옵션이며 경로를 숨기려면 안전한 별칭을 전달해야 합니다.
선택되지 않은 필드 수를 미리보기에 표시하므로 검토할 수 있습니다. 원본 파일 내용 자체를
세척하는 기능은 아니며 선택하지 않은 자유 텍스트에 개인정보가 남을 수 있습니다. 내보내기는
미리보기의 원본 비교값이 아닌 파생 레코드를 사용합니다.

## 선택 내보내기

`export::export_records`는 검색 결과를 페이지로 읽어 JSONL·CSV로 스트리밍합니다. JSONL은
타입이 있는 레코드를 보존합니다. CSV는 경로·MIME·전체 범위 크기·상태·SHA-256·전체 해석의
JSON·진단 수를 포함하며 텍스트 셀을 인용하고 스프레드시트 수식 접두사를 무력화합니다.
비식별화 프로필을 지정하면 파생 레코드만 내보내고 경로 숨김 옵션은 생성된 별칭을 사용합니다.

`export_original_evidence`는 레코드별 메타데이터·원본 바이트·목록을 선택 증거 ZIP으로 만듭니다.
호출자가 가상 항목을 포함해 안전하게 해석하고 연 원본을 전달하며 기록된 크기·SHA-256과
일치해야 합니다. 전체 케이스 스냅샷과는 다른 형식이며 원본 내부 메타데이터가 유지되므로
비식별화 프로필은 받지 않습니다. 원본 세척에는 별도 바이트 수정 기능이 필요합니다.

두 방식 모두 케이스 해시 체인·상태를 검사하고 수정 시점·감사 기준점을 고정하며 결과·바이트
제한과 출력 SHA-256 영수증을 사용합니다. 중간에 케이스가 바뀌면 실패합니다. 같은 디렉터리의
임시 파일로 생성 후 게시하고 기존 파일을 덮어쓰지 않으며 실패한 부분 파일을 남기지 않습니다.
감사 체인의 일관성 확인만으로 케이스 작성자까지 독립 인증하는 것은 아닙니다.

## 조사 보고서

`reporting::build_report`는 케이스 상태를 검증하고 스캔 이력·감사 기준점을 기록한 다음
정규화·교차 검증·필드 출처·발견 사항·타임라인·중복·위치·군집·이동 구간·선택적 기준 스캔
비교를 수행합니다. 선택/전체 개수, 추출 상태, 디코더 가용성을 명시합니다. 잘못된 좌표도
발견 사항에 남기며 공간 계산에서 제외한 이유를 표시합니다. 원본 관측값·저장된 해석과 새
분석을 구분하고 바이너리는 길이·SHA-256으로 표시하며 원본은 케이스에 보존합니다.

검증된 내용 지문을 전달하면 내용 유사도도 비교합니다. 지문 또는 네이티브 미리보기가
없거나 일부만 있으면 분석 범위의 한계로 표시합니다. 보고서의 시각 분석은 제공된 미리보기
방향을 사용하며 다른 방향 비교는 별도 API로 지정할 수 있습니다. 보고서에 원본 파일
바이트를 넣지 않습니다. 재현 가능한 생성을 위해 생성 시각은 호출자가 전달합니다.

`write_report`는 독립 HTML·JSON을 원자적으로 저장합니다. HTML의 증거 문자열은 모두
이스케이프하고 제한적인 CSP를 적용하며 외부 리소스를 불러오지 않습니다. 절 제목은 영어·
한국어·병기를 지원하고 원본 증거와 규칙 설명의 언어는 유지합니다. 반환 영수증에는 출력
길이·SHA-256과 선택적으로 `signed_manifest`의 Ed25519 서명이 들어 있습니다. 독립적으로
신뢰한 공개키와 `verify_manifest`로 검증하고 인증이 필요하면 영수증을 보고서와 함께
보존해야 합니다. 보고서 안의 해시만으로 독립 서명을 대신하지 않습니다. 신뢰한 케이스
기준점을 전달하면 해당 체인의 접두 이력도 확인합니다.

비식별화 보고서는 원래 검색식과 스캔 원본 경로를 제외하고 분석 전에 프로필을 적용하며
파생본 표시를 유지합니다. 제목·분석자·트랙 그룹 이름·선택하지 않은 자유 텍스트는 호출자가
입력한 내용이므로 검토해야 합니다. Rust CLI·GUI는 다음 단계에서 이 API에 연결합니다.

```rust,ignore
let query = metaxtract_analysis::search::parse(&scan_id, "mime=image/jpeg size>=1024")?;
let options = metaxtract_analysis::reporting::ReportOptions::new(
    "Metadata investigation / 메타데이터 조사", "분석자", generated_unix_seconds,
);
let report = metaxtract_analysis::reporting::build_report(
    &case, &query, &options, None, None, Default::default(),
)?;
let receipt = metaxtract_analysis::reporting::write_report(
    &report, "report.html", metaxtract_analysis::reporting::ReportFormat::Html,
    None, Default::default(),
)?;
```
