# 데스크톱 릴리스 안내

[English](releases.md) | [한국어](releases_KR.md)

## 0.2.0

단축키·명령 검색, 내보내기·보안·케이스·진단 도구 분류, CSV/JSONL/HTML/JSON 전달 화면, 미리 보기를 지원하는 비식별화 폼, 보고서·서명·검증 검토, 재사용 프리셋, 재시작 후 유지하는 작업·오류 이력을 추가합니다. 업데이트 확인은 직접 요청할 때만 수행하며 증거 전송·자동 설치는 하지 않습니다. 요약·타임라인 계산 캐시와 문맥에 연결한 비동기 결과 처리로 대용량 화면·케이스 전환을 보강합니다.

| 플랫폼 | 배포 |
|---|---|
| Windows x64 | MetaXtract.exe 실행기, 포터블 ZIP·사용자별 NSIS 설치, 앱·설치 파일 내부 아이콘·버전, 시작 메뉴·선택형 바탕화면 바로가기, 소유 파일만 제거 |
| macOS ARM64 | 앱 번들 정보·아이콘, DMG, 선택 Developer ID·notarytool 지원 |
| Linux x64 | 데스크톱·메뉴 통합, AppImage·DEB, Ubuntu 24.04 빌드 기준과 실제 ABI 요구 사항 기록 |

내부 CLI·GUI·파서는 고정된 상대 위치와 동봉 라이브러리를 사용합니다. 체크섬 검증용 파일·대응 소스·원문 네이티브·Rust·AppImage 고지를 함께 제공하며 libfuse·런타임 원본과 재연결 안내도 포함합니다.

게시 검증은 세 OS 네이티브 빌드·추출 계약·메모리 검사, 패키지 GUI의 스캔·검색·상세·분석·내보내기, 케이스·스키마 호환성, 네이티브 설치·재설치·제거를 포함합니다. 정확한 빌드 커밋·결과는 연결된 CI 검증 보고서를 기준으로 합니다.

Windows 파일은 Authenticode 서명이 없으며 일반 macOS CI 파일은 임시 서명이고 공증되지 않습니다. Developer ID·공증은 별도 자격 정보 구성이 필요합니다. 이번 변경은 데스크톱·배포 개선이며 새로운 메타데이터 추출 형식은 추가하지 않습니다.
